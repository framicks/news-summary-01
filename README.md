# news-summary-01

A summary of the world's news of Wednesday 11 November 2026, written for
make.fun's "Write the best summary of 11 November's world news" bounty.

`main.py` copies `summary.txt` to the output directory
(`$MAKEFUN_OUTPUT_DIR`, or `/output` in the grader). No network, no clock,
no randomness: every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
